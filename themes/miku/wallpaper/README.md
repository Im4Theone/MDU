# Miku wallpaper

Place the original phone wallpaper here as `mobile.jpg`.

The image is not part of the repository: it is third-party artwork (it carries
the artist's signature) and contains trademarked branding, so it cannot be
redistributed under MIT. `mobile.jpg` is listed in `.gitignore`.

MDU never modifies this file. When the wallpaper is enabled it writes a
desktop adaptation to `%LOCALAPPDATA%\MDU\cache\` and applies that instead.
